# T068 完成摘要 — scheduler process_task 頂層例外防護

- 日期: 2026-08-12
- 狀態: ✅ done（commit `34fd968`）
- 類型: fix / priority: high

## 問題
`scheduler.py` 的 `process_task` 沒有頂層 try/except。任何既有分支外的例外（如 `fpath.write_text` 遇到目錄路徑 `IsADirectoryError`、`save_pr_summary`、`count_diff_lines`）都會炸穿 `run()`，中止整個 auto-dev 迴圈，且不執行 `_record_failure`、不做 blocked 升級、不發 Telegram 通知。

## 變更
1. **`scheduler.py` `run()`**：
   - `process_task` 呼叫包 try/except；`KeyboardInterrupt`/`SystemExit` 直接 re-raise 不吞。
   - 其餘例外：`observability.get_logger().exception("task_unexpected_error")` 記錄 + print；未 commit 任務 → `_record_failure`（含 fail_count 遞增、達上限 blocked + blocked review + Telegram 推播）；已 commit 後錯誤 → 僅 `notify_background` 通知，**不觸發 git revert**（保護已提交成果）。
   - 回傳 False 後走既有 `skipped_this_run` 邏輯，同次 run 不重試該任務。
2. **`tests/test_scheduler_exception_guard.py`**（新增，5 tests）：
   - `test_run_continues_after_process_task_unexpected_exception`：第一個任務 raise 後迴圈繼續處理第二個。
   - `test_run_process_task_exception_does_not_revert_committed_work`：已 commit 後異常只通知不 revert。
   - `test_run_uncommitted_task_exception_triggers_record_failure`：未 commit 異常 → `_record_failure` 被呼叫。
   - `test_auto_develop_scheduler_init_params` / `test_scheduler_skipped_this_run_avoids_reprocessing`：防同次重試。
