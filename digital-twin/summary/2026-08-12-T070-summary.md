# T070 完成摘要 — telegram webhook secret token 驗證

- 日期: 2026-08-12
- 狀態: ✅ done（commit `e16b61d`）
- 類型: security / priority: high

## 問題
`/api/webhook` 對任何 POST 照單全收並餵給 aiogram；攻擊者得知網址即可偽造 Telegram Update（如偽造 admin 的 /discuss），繞過 RBAC。

## 變更
1. **`telegram_bot.py`**
   - `WEBHOOK_SECRET`（env `TELEGRAM_WEBHOOK_SECRET`）+ `WEBHOOK_SECRET_HEADER = "x-telegram-bot-api-secret-token"`。
   - `/api/webhook` 開頭：secret 非空時以 `hmac.compare_digest` 比對 header；不符 → 401 `{"ok": false, "error": "unauthorized"}`，不餵 aiogram。相符才處理。未設定時原行為不變。
2. **`scripts/set-tele-webhook.sh`**：`TELEGRAM_WEBHOOK_SECRET` 非空時 `setWebhook` 自動帶 `secret_token=`（Telegram 官方即會回傳該 header）。
3. **`.env.example`**：新增 `TELEGRAM_WEBHOOK_SECRET`（含 T070 說明）。
4. **`docker-compose.prod.yml`**：telegram-bot 透傳 `TELEGRAM_WEBHOOK_SECRET=${TELEGRAM_WEBHOOK_SECRET:-}`。
5. **`tests/test_telegram_bot.py`**（+4）：
   - 設定 secret 後缺 header → 401
   - 錯誤 secret → 401
   - 正確 secret → 通過（200/500，非 401）
   - 未設定 secret → 不拒絶（維持原行為）
