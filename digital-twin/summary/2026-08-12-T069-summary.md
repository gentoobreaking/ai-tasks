# T069 完成摘要 — embedding 降級契約修復

- 日期: 2026-08-12
- 狀態: ✅ done（commit `1e1623f`）
- 類型: fix / priority: medium

## 問題
`embedding.py` 宣稱 embedding 永遠可用（缺模型自動降級 hash），但 `EMBEDDING_PROVIDER=openai` 且無 `OPENAI_API_KEY` 時，`OpenAIProvider.__init__` 在 `get_provider()` 內就 raise `ValueError`（位於 `_safe_embed` 之外），違反降級契約。

## 變更
1. **`embedding.py` `get_provider()`**：`openai` 分支包 try/except `ValueError`（缺 key）→ print 告警 + 降級 `HashEmbeddingProvider()`（沿用 `EMBEDDING_DIM` 設定維度，可比照 `EMBEDDING_PROVIDER=hash` 行為）。
   - 修正落在選擇邏輯（備註分層要求），`_safe_embed` 不動。
   - direct `OpenAIProvider()` 仍 raise（語意保留，測試確認）。
2. **`EmbeddingProvider` 基底**：補 `api_key = ""` 屬性宣告（pyright 型別存取）。
3. **`tests/test_embedding.py`**（+3 tests）：
   - `test_get_provider_openai_without_key_falls_back_to_hash`：缺 key → provider.name == "hash"，`embed`/`embed_query` 回傳確定性 384 維向量、不 raise。
   - `test_get_provider_openai_without_key_respects_embedding_dim`：`EMBEDDING_DIM=128` → 降級向量 128 維。
   - `test_get_provider_openai_with_key_stays_openai`：key 存在 → 仍走 openai。

- [x] key 存在 → 仍走 openai
