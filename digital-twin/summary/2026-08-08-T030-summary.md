## 交付

### incremental_index.py
- `DocSection` 新增 metadata 欄位：`project`、`tags`、`author`、`file_type`、`created_at`、`updated_at`，`to_dict()` 輸出
- schema 新增 6 欄；既有表自動遷移（缺欄 → `add_columns` 補 nullable，不丟資料）
- 建立 `project` / `file_type` / `author` scalar index（加速過濾）
- `extract_file_metadata()` 索引時每檔案提取一次：
  - `project`：路徑推導（`~/tasks/<project>/`、`~/notes/`、本專案）
  - `tags`：frontmatter `tags:`（YAML），無則檔名關鍵字兜底（docker/ci/ai/rag/test...）
  - `author` / `created_at` / `updated_at`：`git log --format=%an/%ci`，失敗退回檔案 mtime
  - `file_type`：spec / task / note / doc
- `build_where(filters)`：AND 合併條件；tags 用 `ARRAY_CONTAINS`；值支援 `>= <= > < =` 前置運算子（日期範圍）
- `parse_filter_spec()`：CLI `--filter 'k=v,k2=v2'`，`|` 分隔多值
- `bm25_search` / `vector_search` / `hybrid_search` 全支援 `filters` 參數；CLI `search` / `rag` 新增 `--filter`
