# algs/signal-grading.md — 硬淘汰與 S/A/B 訊號分級（F10、F12）

## 硬淘汰規則（F10）——任一命中直接剔除，不計分

| # | 規則 | 判定式 |
|---|---|---|
| H1 | 2027 EPS 預估負成長 | earnings_estimate period=+1y 的 `growth < 0`（有資料時）|
| H2 | 最近 3 個月 EPS 大幅下修 | eps_trend 0y：current < 90daysAgo × 0.95（下修逾 5%）|
| H3 | 法人持續大幅賣超 | 外資 20 日淨賣超 **且** 投信 20 日淨賣超 |
| H4 | 基本面無成長只靠題材 | 2026 EPS growth ≤ 0 **且** 近3月營收 YoY 平均 ≤ 0 |
| H5 | 前高極近且 RSI 過熱（降分非淘汰）| 距 60 日高點 < 3% **且** RSI14 > 70 → 總分 −10 |

- H1/H2 在分析師資料缺失時**跳過該規則**並標註「無覆蓋，未檢」
- 淘汰結果輸出到報表「淘汰名單」區塊（含觸發規則編號）

## S/A/B 訊號分級（F12）

前置：通過所有硬淘汰。分級順序由上而下，首個符合即停止：

```
S 級（研究進場）：全部同時滿足
  ├─ R/R ≥ 2.0
  ├─ 因子② ≥ 24（EPS 上修強勁）
  ├─ 因子③ ≥ 14（法人已轉買）
  └─ 2027 EPS 成長 > 0

A 級（等待買點／埋伏股）：
  ├─ 因子② ≥ 18
  ├─ 2027 EPS 成長 > 0
  ├─ R/R ≥ 1.5
  └─ 法人未轉買（因子③ < 14）→ 特徵：基本面好但法人還沒進來

B 級（基本面好&股價偏高）：
  └─ 未達 A，但 total ≥ 60；或觸發 H5 降分後 total 仍 ≥ 60
     典型：EPS 上修 + 法人狂買 + 股價漲多/創新高

淘汰級：任一硬淘汰命中（H5 只降分不淘汰）
```

## 輸出格式

Top 5 表每檔：
`ticker｜name｜sector｜等級(S/A/B)｜total｜2026EPS｜2027EPS｜上修幅度(1M/3M)｜法人20日｜距前高%｜股價｜進場區｜停損｜目標價｜R/R`

每檔附一行結論語（模板拼接，非自由文本）：
- S：「EPS上修＋法人轉買＋低位階＋2027成長，研究進場」
- A：「EPS上修＋2027成長，股價低但法人尚未轉買，埋伏等待」
- B：「基本面佳但股價已反應，僅列觀察」

## 數值例

某股：因子②=27、因子③=15、total=82、2027 growth=+25%、R/R=2.4 → **S 級**
某股：因子②=20、因子③=8、total=70、2027 growth=+18%、R/R=1.8 → **A 級**（法人未轉）
某股：因子②=28、因子③=19、total=75、距前高 1.5% → R/R<1.5 強制 B，且可能觸發 H5 −10
