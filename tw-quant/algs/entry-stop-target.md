# algs/entry-stop-target.md — 進場區／停損／目標價／風報比（F11）

適用對象：**全體 50 檔**（表一即含此欄位）；硬淘汰後的 Top10 再用於 S/A/B 分級。
所有 MA 取**當日值每日重算**（動態），不凍結訊號日。
實作位置：計算邏輯在 T011（量化表欄位），T013 僅消費結果做分級。

## 合理進場區

```
前置資格（沿用 C1/C2）：
  現價 > 60MA 且 60MA 向上 且 現價 > 20MA
  → 不滿足：不輸出進場區，欄位標「架構轉弱，不進場」

若 20MA > 60MA：
  進場區 = [20MA, 20MA × 1.03]
若 20MA ≤ 60MA：
  不給區間，標「待 20MA 站上 60MA 後再評」
```

- 語意：現價高於上緣 →「等回測」；現價在區間內 →「可分批（2~3 筆）」
- 「不落入季線之下」屬於進場資格（C1）與出場紀律（邏輯停損），**不寫入區間幾何**

## 停損（雙軌，先到先出）

| 層級 | 公式 |
|---|---|
| 技術停損 | `min(進場均價 × 0.93, 發動K棒最低點 × 0.995)` |
| 邏輯停損 | 收盤跌破 60MA **且** 日 KD(9,3,3) 死亡交叉 → 無條件出場 |

- 「發動K棒」＝進場日前 10 日內最大量紅 K
- 趨勢初期邏輯停損會先於技術停損觸發（20MA/60MA 差距小），屬預期行為

## 1個月目標價

```
候選A = 近 60 日最高價（第一壓力）
候選B = 分析師目標價 mean（get_analyst_price_targets）
目標價 = 兩者中離現價較近者
若該者漲幅 < 8%（空間不足）：改用較遠者，並在輸出加註「空間不足，降級備註」
```

## 風報比與門檻

```
中值 = (進場區上緣 + 下緣) / 2
R/R = (目標價 − 中值) / (中值 − 技術停損)

R/R ≥ 2.0        → S 級必要條件
1.5 ≤ R/R < 2.0  → 最高 A 級
R/R < 1.5        → 強制 B 級
```

## 數值例（台積電，2026-08-25 實抓）

- 現價 2375、分析師 mean 3229、假設近 60 日高 2450、20MA 2330、60MA 2250
- 資格通過（2375>2330>2250）；進場區 = [2330, 2400]、中值 2365
- 技術停損 = min(2365×0.93, …) ≈ 2199
- 目標價 = min(2450, 3229) = 2450（漲幅 3.6% <8% → 改用 3229？否——較遠者是 3229，
  改用並加註）
- R/R 以改用前保守值計算：(2450−2365)/(2365−2199) ≈ 0.51 → 強制 B 級
  （已漲上去的標的不是「還沒漲」，此結果符合策略意圖）
