# T006 - 四燈號健診評分系統

## 目標
實作四燈號（基本面／籌碼面／技術面／估值面）多因子評分系統，將原始條件轉換為視覺化燈號與綜合分數，支援強度分級與信心水準。

對應規格：`§3.2.2 多因子評分`、`§3.2.2 四燈號健診系統`

## 驗收標準
- [ ] 基本面評分：EPS年增率(40%)、月營收年增率(30%)、毛利率年增差(30%)
- [ ] 籌碼面評分：外資近5日佔20日均量(40%)、投信近5日佔20日均量(30%)、券資比(30%)
- [ ] 技術面評分：均線排列(40%)、RSI(14)(30%)、布林通道位置(30%)
- [ ] 估值面評分：本益比河流位置(40%)、股價淨值比河流位置(30%)、殖利率(30%)
- [ ] 每項子指標依門檻輸出 🟢/🟡/🔴 燈號
- [ ] 四面向各權重 25%，計算綜合總分（0–100）
- [ ] 綜合評分對應五級燈號意義（≥80 🟢 / 60~79 🟢🔴 / 40~59 🟡 / 20~39 🔴🟢 / <20 🔴）
- [ ] 每條規則/子項有明確的數據來源與門檻（規格內定死或回測決定）
- [ ] 輸出每日燈號報告（文字/表格）

## 備註
- 門檻值初期可由回測決定，後續可依市場狀態動態調整（§分市場狀態運作）
- 此為第二階段核心產出，需先完成 T001–T004
