# T008 - 風險控管模組

## 目標
建立風險控管模組，提供波動率監控、最大回撤追蹤、訊號衝突警示與建議觀察停損區，輔助使用者控制下檔風險。

對應規格：`§3.2.2 風險模組`、`§6 風險與限制`

## 驗收標準
- [ ] 近期波動率計算（標準差 / ATR），偏離均值時發出警示
- [ ] 最大回撤監控（從近期高點回落幅度）
- [ ] 訊號衝突警示（多空條件同時觸發時標記衝突）
- [ ] 建議觀察停損區（非自動下單，僅提示參考價位）
- [ ] 風險警示等級分級（注意/警告/嚴重）
- [ ] 所有風險指標記錄至 DB，可回溯查詢
- [ ] 支援 Telegram / Discord 即時推播風險警示

## 備註
- 此為「輔助判斷」工具，不與下單介面連接
- 最終下單與風險承擔由使用者負責（§6）
