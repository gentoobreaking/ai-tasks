# T009 - 儀表板與績效追蹤

## 目標
建置盤後總覽儀表板，展示四燈號健診結果、規則觸發狀態，並建立訊號績效追蹤系統，記錄訊號出現後的實際表現。

對應規格：`§3.2.1 基礎儀表板`、`§3.2.2 績效追蹤`、`§5 評估指標`

## 驗收標準
- [ ] 盤後總覽儀表板（建議擴充既有 Flask 前端，加入訊號頁籤）
- [ ] 顯示即時四燈號健診結果（四面向分數 + 綜合總分）
- [ ] 顯示每條規則觸發狀態
- [ ] 績效追蹤：訊號出現後 1/3/5 日表現
- [ ] 統計報表：勝率、盈虧比、連續虧損次數
- [ ] 依市場狀態分類統計（多頭/空頭/震盪）
- [ ] 支援查詢歷史訊號紀錄
- [ ] 績效數據每日自動更新

## 備註
- 建議直接擴充既有的市場資料儀表板，不另起一套
- 儀表板僅供檢視，不提供下單功能
