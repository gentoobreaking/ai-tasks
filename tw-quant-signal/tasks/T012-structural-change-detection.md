# T012 - 結構變化偵測

## 目標
監控規則與模型是否隨時間逐漸失效，透過滾動勝率、報酬、觸發頻率等指標偵測績效衰退與分布偏移。

對應規格：`§3.3.2 結構變化偵測`、`§3.3.3 評估層`

## 驗收標準
- [ ] 規則觸發頻率偏離歷史分布時告警
- [ ] 滾動勝率/報酬持續低於回測基準時告警
- [ ] 特徵分布隨時間出現位移時偵測（可視化）
- [ ] 衰退偵測結果每日輸出報告
- [ ] 支援通知推播（規則衰退、需重新評估）
- [ ] 衰退規則自動標記，不自動停用（由人決定）

## 備註
- 研究環境與實戰環境分離後（T013），此模組主要作用於實戰環境
- 僅監控與通知，不自動停用規則
