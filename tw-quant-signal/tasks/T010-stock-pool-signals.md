# T010 - 個股池訊號

## 目標
在大盤傾向下，擴充至精選觀察個股清單，篩選相對強弱個股或族群，產出個股層級的燈號健診報告。

對應規格：`§3.3.2 個股層訊號`、`§3.3.1 個股池訊號`

## 驗收標準
- [ ] 定義精選觀察清單（至少 10–20 檔）
- [ ] 每檔個股可產出四燈號健診報告
- [ ] 個股評分納入「相對大盤強弱」校正因子
- [ ] 支援族群/產業分組檢視
- [ ] 個股資料來源涵蓋歷史上曾存在標的（避免存活者偏誤）
- [ ] 大盤訊號與個股訊號可交叉比對
- [ ] 儀表板支援個股清單總覽與篩選

## 備註
- 存活者偏誤在此階段需納入處理
- 個股數量初期不宜過大，聚焦觀察清單
