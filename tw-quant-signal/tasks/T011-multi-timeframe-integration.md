# T011 - 多時間框架整合

## 目標
整合日線與週線時間框架，產出不同週期下的燈號訊號，並提供多時間框架共識判斷（如：日線偏多 + 週線偏多 = 強烈偏多）。

對應規格：`§3.3.1 多時間框架整合`

## 驗收標準
- [ ] 週線級別的四燈號健診計算
- [ ] 日線燈號與週線燈號的整合規則
- [ ] 多時間框架共識判斷邏輯
- [ ] 短線（1–5日）、波段（1–4週）訊號分類輸出
- [ ] 儀表板同時顯示多時間框架燈號
- [ ] 中期（1–3個月）框架預留擴充點

## 備註
- 此為第三階段進階功能，需先完成 T006（四燈號健診）與 T009（儀表板）
