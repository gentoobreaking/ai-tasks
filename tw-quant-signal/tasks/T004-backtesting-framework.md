# T004 - 回測框架

## 目標
建立完整回測框架，驗證每條規則在歷史資料上的表現，並依回測方法論（§3.1.7）避免過度配適與未來函數。

對應規格：`§3.1.7 回測方法論注意事項`、`§5 評估指標`

## 驗收標準
- [x] 回測至少覆蓋 3–5 年歷史資料 — 1106 個交易日 (~4.4 年, 2022-01 ~ 2026-07)
- [x] 回測期間包含多頭、空頭、盤整三種市場狀態 — 多頭 49.5% / 空頭 19.0% / 盤整 31.4%
- [x] 使用 T-1 資料，完全避免未來函數 — 每日期 `WHERE trade_date<=as_of`，只用當日收盤前已知資料
- [x] 歷史資料切分「規則設計期」與「樣本外測試期」— IS: 2022-2024 (727 日), OOS: 2025-2026 (379 日)
- [x] 交易成本計入：證交稅 0.3% + 手續費 0.1425% × 0.6 折（`CostModel` 可調）
- [x] 每條規則輸出統計報告：勝率、平均報酬、盈虧比、最大回撤、連續虧損次數
- [x] 記錄測試過的規則總數 — 4,819 次規則評估（避免多重檢定偏誤）
- [x] 成本模型隨稅率變動可調整參數 — `CostModel(tax_sell, tax_daytrade, commission, discount)`

## 備註
- 存活者偏誤於第三階段擴充個股池時處理
- 回測結果僅供參考，歷史有效 ≠ 未來有效
