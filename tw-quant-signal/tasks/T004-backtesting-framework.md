# T004 - 回測框架

## 目標
建立完整回測框架，驗證每條規則在歷史資料上的表現，並依回測方法論（§3.1.7）避免過度配適與未來函數。

對應規格：`§3.1.7 回測方法論注意事項`、`§5 評估指標`

## 驗收標準
- [ ] 回測至少覆蓋 3–5 年歷史資料
- [ ] 回測期間包含多頭、空頭、盤整三種市場狀態
- [ ] 使用 T-1 資料，完全避免未來函數
- [ ] 歷史資料切分「規則設計期」與「樣本外測試期」
- [ ] 交易成本計入：證交稅 0.15%–0.3% + 手續費 0.1425%（可調參數）
- [ ] 每條規則輸出統計報告：勝率、平均報酬、盈虧比、最大回撤、連續虧損次數
- [ ] 記錄測試過的規則總數（避免多重檢定偏誤）
- [ ] 成本模型隨稅率變動可調整參數

## 備註
- 存活者偏誤於第三階段擴充個股池時處理
- 回測結果僅供參考，歷史有效 ≠ 未來有效
