# T013 - 研究/實戰分離與操作治理

## 目標
建立研究（自由回測與實驗）與實戰（僅使用通過驗證穩定規則）兩套環境，並納入操作日誌、責任紀錄與法規邊界檢查。

對應規格：`§3.3.2 研究與實戰分離`、`§3.3.2 合規與操作邊界`、`§6 法規邊界`

## 驗收標準
- [ ] 研究環境：自由調整參數、測試新規則、獨立回測
- [ ] 實戰環境：僅使用通過驗證的穩定規則，鎖定版本
- [ ] 規則從研究晉升至實戰須通過審核流程（手動）
- [ ] 操作日誌：記錄每次訊號產出、規則版本、觸發條件
- [ ] 決策責任紀錄：訊號僅供參考，人為最終決定
- [ ] 法規邊界文件化：定位為個人使用工具，不涉及投顧業務
- [ ] 若未來考慮對外提供訊號，提示需法規評估

## 備註
- 此為長期治理架構，初期可先以文件規範为主
- 操作日誌同時可作為結構變化偵測（T012）的輸入
