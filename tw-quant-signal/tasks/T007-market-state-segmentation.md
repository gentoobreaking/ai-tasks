# T007 - 分市場狀態運作

## 目標
區分多頭、空頭、震盪市三種市場狀態，在不同狀態下套用不同的規則權重與燈號門檻，提升訊號在不同市場環境下的適應性。

對應規格：`§3.2.2 分市場狀態運作`

## 驗收標準
- [ ] 定義多頭/空頭/震盪市的判斷標準（如：指數 vs 年線、趨勢強度指標）
- [ ] 每種狀態下可設定不同的規則權重
- [ ] 狀態偵測可自動每日更新
- [ ] 同一規則在不同市場狀態下有獨立統計報告
- [ ] 狀態切換有明確記錄與通知
- [ ] 支援回測時指定市場狀態進行分組績效分析

## 備註
- 需先完成規則引擎（T003）與回測框架（T004）
- 狀態切換不宜過度敏感，避免頻繁切換導致訊號不穩定
